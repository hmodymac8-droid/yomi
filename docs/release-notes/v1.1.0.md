### What's new
- **English / Arabic switch** on Discover: show only English sites or only Arabic sites.
- **Automatic updates**: from this version on, Yomi updates itself when a new release comes out.
- Arabic descriptions now read right to left.
- [Sites that work smoothly with Yomi](https://github.com/hmodymac8-droid/yomi#sites-that-work-smoothly-with-yomi), with their links, in the README.

### Install
Download **Yomi-Setup-1.1.0.exe** below and run it (it keeps your library). If Windows shows *"Windows protected your PC"*, click **More info → Run anyway**.
